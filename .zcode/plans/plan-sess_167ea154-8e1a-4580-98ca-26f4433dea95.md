# 技能库页（MySkills）改造方案

## 目标
两个功能：
1. **点技能卡片的「+添加标签」按钮 → 弹出浮动标签选择面板**（搜索 + 标签列表 + 新建标签），替代当前的内联 `<input>` 输入。
2. **顶部加一个按钮 → 弹窗显示所有「技能名:介绍」一行一个 + 复制全部**。

只改 `MySkills.tsx` 一个文件 + 三语 i18n。复用已有的 `api.setSkillTags` / `api.getAllTags` / 剪贴板插件，不改后端/Rust。

## 改动点

### 1. 浮动标签选择面板（功能1）
**触发**：卡片右下角现有的「+」按钮（grid 卡片 MySkills.tsx:1352-1359，list 卡片 L1411 附近）。把 `tagEditSkillId === skill.id ? <input> : <button>` 的二选一，改成统一的「点击 → 打开浮动面板」逻辑。

**状态**：
- `tagPickerSkillId: string | null`（当前打开标签面板的技能 id）
- `tagPickerSearch: string`（面板内搜索框）
- 复用已有 `tagInput` state 给搜索框用，或新增。

**面板内容**（grid 和 list 两处都要渲染，复用同一段 JSX 或抽成内联渲染函数 `renderTagPicker(skill)`）：
- 固定/绝对定位浮层（`absolute`），挂在 `+` 按钮所在行下方，`z-50`，`max-h-[300px]` 可滚动（"挺长的"）。
- 顶部一个搜索 input（`filter` 已有的 `getTagOptions(skill, keyword)` 函数）。
- 标签列表：复用 `getTagOptions(skill, search)` 返回的候选标签，点击即调用 `handleAddTag(skill, tagOption)`。
- 底部「+ 新建 `keyword`」：当搜索词不为空且不在候选里时，显示新建项，点击调 `handleAddTag(skill, keyword)`。
- 点击面板外（backdrop）或 Esc 关闭。

**逻辑复用**：`handleAddTag` / `handleRemoveTag` / `getTagOptions` 全部已存在，不改。面板内已绑定的标签用 `getTagOptions` 过滤掉（它已经排除 `skill.tags`），所以面板只显示"可添加"的，再加一个"当前标签（可点 × 删除）"区域，让面板既能加也能删。当前标签区复用 `skill.tags` + `handleRemoveTag`。

**多卡片并发**：同时只开一个面板（单 state），点别的卡片自动切换（`setTagPickerSkillId(skill.id)`）。

### 2. 技能清单弹窗（功能2）
**按钮位置**：标题行 `app-page-header`（MySkills.tsx:948-956）右侧。文案「技能清单」/「Skills List」，图标 `ListText` 或 `FileText`。

**状态**：`skillsListOpen: boolean`。

**弹窗**：新建内联组件 `SkillsListDialog`（直接写在 MySkills.tsx 文件内，不单独建文件，因为只此一处用）。
- 全屏遮罩 + 居中卡片（复用 `fixed inset-0 z-50 ... bg-black/40` + `bg-surface rounded-lg`，沿用 HelpDialog / BatchTagDialog 风格）。
- 内容区：`<pre className="whitespace-pre-wrap">` 或 div + 每行一个，渲染 `filtered`（当前筛选结果）或全部 `skills`。**用当前筛选结果 `filtered`**，更符合"看到什么导出什么"；但顶部加一行计数说明。
- 每行格式：`{name}: {description || "-"}`，name 用 `skillDisplayNames.get(skill.id)`（与卡片一致，重名会带目录名）。
- 底部「复制全部」按钮：拼成 `${name}: ${desc}\n` 多行，调 `clipboardWriteText`（`@tauri-apps/plugin-clipboard-manager`），成功 toast（复用现有 `t("promptPreview.copied")` 或加新 key）。
- 「关闭」按钮。

## 不改动项
- 后端 Rust、`tauri.ts` API、`sync_skill_to_tool` 逻辑 —— 全部复用。
- `BatchTagDialog`（多选模式批量改标签）—— 与本次单技能面板并行存在，不冲突。
- 卡片点击打开详情（`openSkillDetailById`）行为 —— 不变，只有「+」按钮触发面板。
- list 视图原本没有内联「+添加标签」，本次给它也加上同样的「+」按钮 + 面板（grid/list 体验一致）。

## 验证
- `pnpm lint`（eslint）通过。
- `pnpm build`（tsc -b && vite build）类型与构建通过。
- 手动：技能库页 → 点卡片「+」→ 弹出长浮层，能搜/选/新建标签，能删除已有标签，Esc 关闭 → list 视图同样可用 → 点顶部「技能清单」→ 弹窗逐行显示 → 复制全部到剪贴板。

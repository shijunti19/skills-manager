## 背景诊断

**"添加标签弹窗没标签"的根因**:项目有两套标签系统并存——
- **简单标签** `skill_tags`(技能字段里的字符串):技能卡上的 tagPicker(`MySkills.tsx:1087`)只读这个,通过 `getAllTags()` 拿"所有技能用过的标签去重"。没技能用过标签 → 空。
- **智能标签** `smart_tags`(独立表 + 多对多关系 + prompt):在 TagsView(标签管理页)和 SkillTagFilter 里用。

你在标签管理页建的智能标签,技能卡的添加标签弹窗**根本读不到**。按你的决策,统一走 smart_tags,我会顺手修这个弹窗让它也能读智能标签。

## 统一格式设计(导入 = 清单输出,双向兼容)

```
# 🚀 项目初始化
这是标签描述,可写多行,作为标签的 description 字段。

- a031-bootstrap: 技能介绍文字 | https://github.com/xxx | C:/Users/.../a031-bootstrap
- bmad-generate-project-context: 技能介绍 | github地址 | 目录地址

# 🎯 需求对齐
这个标签的描述。

- grill-me: 介绍 | github | 目录
- grill-with-docs: 介绍 | github | 目录
```

**格式规则**:
- `# 标签名` 开头一个新标签(标签名后的 emoji/文字都作为标签 name)
- 标题下到下一个 `#` 之间的**非列表行** = 标签 description(可选)
- `- 技能名: 介绍 | github | 目录` = 技能绑定行(按技能名匹配本地技能库)
- 技能名匹配不到的行 → 忽略并统计(像 TagsView 现有的 unmatched 提示)
- 解析时按标签出现顺序设 sort_order

## 三个改动

### 改动 1:修复"添加标签弹窗没标签"(`MySkills.tsx` 的 `renderTagPicker`)

让 tagPicker 同时显示智能标签(smart_tags)。点智能标签时调用 `bindSmartTagsToSkill` 绑定;点简单标签维持原逻辑。视觉上分组显示:"智能标签"区 + "简单标签"区。需要把 `smartTags` + `smartTagsMap` 从父级传进来(或直接在 MySkills 里加载——MySkills 目前没加载 smart_tags,需要加加载逻辑)。

> 注:这个改动较大,涉及给 MySkills 注入 smart_tags 数据流。如果你只想要核心的清单+导入功能,这个可以作为第二优先级。我在实现时会先做 2、3,再做 1。

### 改动 2:"技能清单"按钮输出新格式(`MySkills.tsx` 的 `SkillsListDialog`)

改造 `SkillsListDialog`(`MySkills.tsx:126`):
- 入参从 `entries: {name, description}` 改为接收 `smartTags` + `smartTagsMap` + `skills`(完整 ManagedSkill)
- 输出按上面的统一格式生成:
  - 顶部先列出所有标签名 `标签1;标签2;...`(如你要的"所有的标签 显示在上面")
  - 然后每个 `# 标签` 下挂该标签的技能 `- 技能名: 介绍 | github | 目录`
  - 技能介绍为空时,截取 source_ref(github) 或 central_path(目录) 填充
- 顶部加一个"按标签分组 / 纯列表"切换(可选,保留原纯列表模式作为 fallback)
- 复制按钮维持

github 地址取 `skill.source_ref`(git 类型)或 `skill.source_ref_resolved`;目录取 `skill.central_path`。

### 改动 3:标签管理页新增"导入"功能(`TagsView.tsx`)

在 `TagsView.tsx` 顶部"新建标签"按钮旁边加一个**「导入」按钮**:
- 点击弹出一个 Modal:大文本框 + "保存"按钮 + 格式说明
- 文本框预填当前已有的标签+绑定(用统一格式导出),方便用户在现有基础上编辑
- 点"保存":
  1. 弹确认框:"将清空所有智能标签和绑定关系,按文本重建,确认?"
  2. 调用新后端命令 `import_smart_tags_from_text(text)` —— 原子操作:事务内 DELETE smart_tags + skill_smart_tag_relations → 解析文本 → INSERT 标签 + 绑定
  3. 解析在后端做(Rust),返回 `{ tags_created, bindings_created, skills_unmatched: [...] }`
  4. 前端 toast 提示结果,unmatched 的技能名列表展示出来
  5. 刷新页面

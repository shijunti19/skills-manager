# 实施计划：新增"清空技能描述"按钮

## 目标
在 `SkillTagFilter.tsx` 的"同步全部到 zcode"按钮**右侧**再加一个按钮。点击时：
1. **前置校验1**：全局 `sync_mode` 必须 = `"copy"`（文件复制），否则报错中止。
2. **前置校验2**：该 agent 目录下每个技能目录不能是软连接/junction（`symlink_metadata().is_symlink()` 必须为 false），否则列出违规技能名报错中止。
3. **执行**：遍历 agent 目录下每个技能的 `SKILL.md`（或 `skill.md`），把 frontmatter 里的 `description` 字段**整行删除**（支持单行值、带引号值、块标量 `|`/`>` 多行值）。

按钮作用范围：**整个 agent 目录的所有技能**（与"同步全部"按钮的语义解耦——同步全部按标签集，本按钮按整个目录）。

## 后端改动（Rust）

### 1. `src-tauri/src/core/skill_metadata.rs`（新增写入能力）
当前只有 `parse_skill_md`（只读）。新增两个 pub 函数：

- `pub fn strip_description_from_skill_dir(dir: &Path) -> std::io::Result<StripOutcome>`
  - 枚举 `StripOutcome { Stripped, NoDescription, NotASkill }`
  - 找 `SKILL.md` → `skill.md`，读内容，调 `strip_description_line`，若变化则写回。
- `pub fn strip_description_line(content: &str) -> String`
  - 仅当 frontmatter 存在（首行 `---` 且能找到第二个 `---`）时处理。
  - 在 frontmatter 段内定位 `description:` 开头的行：
    - 值是 `|` 或 `>` 开头 → 块标量，连带删除后续所有缩进/空行（直到下一个顶级 key 或 `---`）。
    - 否则 → 单行，只删这一行。
  - 保留原文件所有其他内容/格式/行尾，**不使用 serde_yaml 反序列化再序列化**（避免重排 frontmatter）。
  - 未找到 `description` 行则原样返回（标记为 `NoDescription`）。

配套单元测试（沿用文件已有的 `tempdir` + `fs::write` 风格）：
- `strip_description_single_line`
- `strip_description_quoted_value`
- `strip_description_block_scalar_literal`（`|`）
- `strip_description_block_scalar_folded`（`>`）
- `strip_description_no_frontmatter_unchanged`
- `strip_description_no_description_field_unchanged`
- `strip_description_preserves_other_fields`
- `strip_description_preserves_body_content`

### 2. `src-tauri/src/commands/agent_workspace.rs`（新增命令）
新增 `#[tauri::command] pub async fn strip_agent_skill_descriptions(...)`：
- 签名：`(store, agent: String) -> Result<StripDescriptionsDto, AppError>`
- 返回 DTO：`{ stripped: usize, skipped: usize, total: usize }`
- 流程（在 `spawn_blocking` 内）：
  1. `adapter_for_agent(&store, &agent)?` → 取 adapter；若未安装/disabled 报错（复用 `organize_agent_skills` 的检查模式）。
  2. 读 `store.get_setting("sync_mode")` → 经 `sync_engine::sync_mode_for_tool` 解析。若不是 `SyncMode::Copy`，返回 `AppError::invalid_input("默认同步模式必须是「文件复制」...")`。
  3. `read_agent_local_skills(&adapter)` 拿到技能列表。
  4. **逐个检查软连接**：对每个 `skill.path`，`std::fs::symlink_metadata(&path)`，若 `file_type().is_symlink() == true`，收集到 `symlink_names` 列表。
  5. 若 `symlink_names` 非空，返回 `AppError::invalid_input(format!("以下技能是软连接，请先切换到文件复制模式并重新同步：{}", names.join(", ")))`。
  6. 否则遍历每个 skill 目录，调 `skill_metadata::strip_description_from_skill_dir`，累计 `Stripped` / `NoDescription` 计数。
  7. 返回 DTO。

### 3. `src-tauri/src/lib.rs`（注册命令）
在 `// Agent local workspace` 分组末尾追加：
```
commands::agent_workspace::strip_agent_skill_descriptions,
```

## 前端改动（TS/TSX）

### 4. `src/lib/tauri.ts`（新增 API）
在 `organizeAgentSkills` 附近：
```ts
export interface StripDescriptionsResult {
  stripped: number;
  skipped: number;
  total: number;
}
export const stripAgentSkillDescriptions = (agentKey: string) =>
  invoke<StripDescriptionsResult>("strip_agent_skill_descriptions", { agentKey });
```

### 5. `src/views/extensions/SkillTagFilter.tsx`（新增按钮）
- import 新增 lucide 图标 `FileText`（或 `Eraser`）。
- 新增 state：`const [stripping, setStripping] = useState(false);`
- 新增 handler `handleStripDescriptions`：
  - 调 `api.stripAgentSkillDescriptions(agentKey)`
  - 成功 → `await onRefresh()` + `toast.success(t("promptPreview.stripDone", { agent, stripped, skipped }))`
  - 失败 → `toast.error(typeof err === "string" ? err : t("promptPreview.stripFailed"))`（让后端的具体校验错误能透出，如"必须文件复制模式"）
- 在"同步全部"按钮（`{agentKey && (...)}`）的 `}` 前、`</button>` 后追加第三个按钮（同样 `{agentKey && (...)}` 条件），样式与"同步全部"完全一致（`bg-surface` + `hover:bg-surface-hover`），文案 `t("promptPreview.stripDescriptions")`，`title` 用 `t("promptPreview.stripDescriptionsHint")`。
- 注意：**不**加 `disabled={tagSkills.length === 0}` 条件——因为这个按钮作用于整个目录，与标签选择无关，始终可点。

### 6. i18n（en.json / zh.json / zh-TW.json 的 `promptPreview` 命名空间）
新增 4 个 key：

| key | zh | en | zh-TW |
|---|---|---|---|
| `stripDescriptions` | 清空描述 | Strip descriptions | 清空描述 |
| `stripDescriptionsHint` | 文件复制模式下，清空本 Agent 目录下所有技能 SKILL.md 的 description 字段（避免 AI 加载冗余上下文） | Under copy mode, clear the description field of every skill's SKILL.md in this agent's directory (so the AI context won't load them) | 檔案複製模式下，清空本 Agent 目錄下所有技能 SKILL.md 的 description 欄位 |
| `stripDone` | 已清空 {{agent}} 下 {{stripped}} 个技能的描述（跳过 {{skipped}} 个） | Stripped descriptions from {{stripped}} skills under {{agent}} ({{skipped}} skipped) | 已清空 {{agent}} 下 {{stripped}} 個技能的描述（跳過 {{skipped}} 個） |
| `stripFailed` | 清空描述失败 | Failed to strip descriptions | 清空描述失敗 |

## 验证
1. `cargo test -p skills-manager --lib skill_metadata` 跑新增的单测。
2. `pnpm tsc --noEmit`（或 `pnpm build`）验证前端无类型错误。
3. 手测：设置页切到"文件复制"，到 zcode 标签筛选条点新按钮，确认 toast 成功 + 用 `cat C:\Users\52752\.zcode\skills\<某技能>\SKILL.md` 确认 description 行已删除。
4. 手测失败路径：切回"符号链接"模式，再点按钮，确认 toast 报错"必须是文件复制"。

## 不改动
- `organize_agent_skills`、"同步全部"按钮逻辑、`sync_engine` 全部保持不变。
- 不动 `AppContext`、不动 `Settings.tsx`。
- 不改 description 字段为空字符串（采用更干净的"整行删除"方案，符合用户"全删了"的措辞）。

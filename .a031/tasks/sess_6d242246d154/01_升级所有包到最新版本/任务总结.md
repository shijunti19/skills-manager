## 关键决策

1. **store 损坏处理**：用户反馈 `X:\.pnpm-store` 被手动删过导致不完整。清理 node_modules + lockfile + 全局 store 后 `CI=true pnpm install` 全量重下，解决 `esbuild` 构建脚本被跳过的误报。
2. **Vite 8 不再依赖 esbuild**：改用 rolldown + lightningcss。`pnpm` 报 esbuild ignored builds 实际是误报（项目根本不需要 esbuild）。
3. **Tailwind 4 兼容**：现有 CSS 已用 `@import "tailwindcss"` + `@config "../tailwind.config.js"` 兼容写法，无需重写。PostCSS 自动切到 `@tailwindcss/postcss`。
4. **keyring 4 feature 重构**：旧 feature `apple-native`/`windows-native` 改为 optional dep，用 `features=["v1"]` 保持旧 API 兼容。
5. **aes-gcm 0.11 破坏性 API**：三处签名变化（`new`/`encrypt`/`decrypt` 都要引用），按编译器提示逐一修复。

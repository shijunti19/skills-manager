3a. SkillTagFilter 改为「受控选中 + 上报选中标签的 skillIds」
文件：src/views/extensions/SkillTagFilter.tsx

props 新增 selectedTagIds: Set<string> 与 onSelectTags: (ids: Set<string>) => void（把当前内部的 selectedTagIds state 提升到父组件），保留 managedSkills、smartTagsMap。

3b. WorkspaceView 用选中标签替换主列表（备份原列表）
文件：src/views/WorkspaceView.tsx

新增 state：const [tagFilterSelected, setTagFilterSelected] = useState<Set<string>>(new Set());（选中的 smart tag id）。
计算 tagFilteredSkills: ManagedSkill[]：若 tagFilterSelected.size === 0 → null（表示未启用标签筛选，显示原列表）；否则从 smartTagsMap（skill_id→tag_id[]）取与所选标签交集的 skillId，再映射到 managedSkills。
渲染分支：当 tagFilteredSkills !== null（即用户选了标签），主列表区域（L950-979 的 grid/list）整体替换为渲染 tagFilteredSkills，每个技能卡用新组件 TagSkillRow；并在列表顶部加一个「显示全部 / 取消筛选」按钮，点了 setTagFilterSelected(new Set()) 切回原列表。原 visibleLocalSkills 渲染逻辑保持不动作为「备份/默认」分支。
<SkillTagFilter> 传入 selectedTagIds={tagFilterSelected} onSelectTags={setTagFilterSelected}。
3c. 新组件 TagSkillRow（单技能：已同步/未安装 + 同步按钮）
文件：src/views/extensions/SkillTagFilter.tsx 内导出，或新建 src/views/extensions/TagSkillRow.tsx（推荐新建，职责清晰）。

props：skill: ManagedSkill、agentKey: string | null、onSynced: () => Promise<void>（父组件传 handleSheetInstalled 同款的三件套刷新）。
状态判定：const isSynced = skill.targets.some(t => t.tool === agentKey);（复用 existsInGlobal 同款逻辑）。
渲染：技能名 + description（skill.description）+ 标签 chips（skill.tags）。
已同步：右侧 emerald 徽章 已同步 / Synced（类 bg-emerald-500/10 text-emerald-600 dark:text-emerald-400，复用 SkillPickerRow 现成风格），无按钮或灰置。
未安装：右侧 未安装 / Not installed 徽章（类 bg-surface-hover text-muted）+ 「同步」按钮。
「同步」按钮点击：await api.syncSkillToTool(skill.id, agentKey) → await onSynced()（刷新 managedSkills/tools/localSkills，按钮转 loading 用 Loader2）。成功 toast 已同步到 {agent}，失败 toast 用 getErrorMessage。后端 sync_skill_to_tool 已按全局 sync_mode（symlink/copy）自动落地，前端无需关心软连接还是复制。
样式沿用代码库现有：卡片行 flex items-center gap-3 px-4 py-2.5 rounded-md border border-border-subtle；同步按钮主色 bg-accent text-white（与「+ 添加」主按钮一致），hover bg-accent-hover。
